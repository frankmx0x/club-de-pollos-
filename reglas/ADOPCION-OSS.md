# Protocolo de adopción de repo open source (ANTES de construir encima)

Cuando Francisco pase el repo candidato:

1. **LICENCIA primero** — con socios es tema legal (MIT/Apache vs GPL/AGPL cambia todo).
   Va a DECISIONS.md.
2. **Salud** — actividad, issues, ¿mantenedor único o comunidad? Un repo muerto es
   nuestro desde el día uno.
3. **El README es su "planeado", el código su "construido"** — sesión de exploración con
   reporte antes de la primera línea encima.
4. **Decidir y registrar el modo**: dependencia / fork-and-own / solo inspiración.
5. **Frontera limpia**: lo ajeno en su capa; nuestras invariantes aplican a NUESTRO
   código aunque el repo adoptado no las tenga.
